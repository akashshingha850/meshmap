# P1 — Mesh networking with BATMAN-adv

[← Docs index](../README.md)

Pipeline 1 asks how much imagery and telemetry a flying multi-hop mesh can carry, and how fast it recovers when links break. Its main outputs are a link-capacity model and a tuned mesh and ROS 2 transport. Pipeline 2 uses the model as a planning constraint, and Pipeline 3 uses it as a bandwidth budget.
